ISSUES & SUGGESTIONS
🔴 진행 중인 밸런스 개선
✅ 자원 시스템 활성화
분노: 강타(3비용), 스위치(1비용), 관통(5비용) | 기력: 도약(20비용) 스킬 추가
✅ 기력 최대값 통일
암살자, 궁수, 노비스, 무투가, 공병 → 모두 기력 100으로 표준화
✅ 클래스명 정리
tanker → knight (기사) 변경. 2차 전직 시 직군으로 활용 가능
✅ 캐릭터 개성화
생성 시 스탯에 ±20% 랜덤 변동 추가. 같은 클래스여도 개별 특성
🟡 스킬 도입 전 밸런스 조정 제안
추천
궁수 HP 60 → 70
최소한의 생존력 확보. 암살자에게 2타→3타 사망으로 개선.
HP 60 / DEF 3→HP 70 / DEF 3
추천
탱커 ATK 15 → 18
최소 위협감 부여. 궁수(DEF 3) 상대 시 15→18 데미지.
ATK 15 / DEF 20→ATK 18 / DEF 20
선택
마법사 HP 65 → 70
궁수와의 차별성 유지 + 약간의 생존 버퍼.
HP 65 / DEF 4→HP 70 / DEF 4
선택
사제 ATK 20 → 22
치유량 30→33으로 소폭 상승. 생존 시 가치 증가.
ATK 20 / 치유 30→ATK 22 / 치유 33
