## 4. 용어집

| 용어 | 뜻 |
|---|---|
| **클랜원** | 아군 캐릭터(사용자가 쓰는 용어). 코드에서는 `ally`/`char`/`unit` |
| **지휘관** | 주인공(기본 이름 리안). 전투에 안 나감 |
| **노비스** | 시작 직업. 아카데미에서 전직 가능한 유일한 직업 |
| **전직** | 노비스 → 다른 직업 (전직서 1장) |
| **승급** | 클랜원 **등급**(C→B→A→S)을 올림 (성소, 제물+영혼석). 아래 "등급"과 구분 |
| **등급 (클랜원)** | 잠재력으로 정해지는 C/B/A/S. 레벨 상한과 능력치 배율을 정함 |
| **등급 (장비)** | 일반(D)·고급(C)·희귀(B)·영웅(A)·전설(S) |
| **잠재력** | 클랜원이 만들어질 때 굴린 HP/ATK/DEF 성장 폭(+행동속도 보정) |
| **영혼석 / 조각** | 승급 재료. 조각 10개 = 영혼석 1개, 직업별 |
| **성소** | 부활·승급·개명·마법부여 화면 |
| **아카데미** | 전직·스킬북 화면 |
| **아지트** | 로비 가운데의 클랜 방 장면 |
| **요일 던전** | 요일마다 직업이 바뀌는 반복 던전 (하루 3회) |
