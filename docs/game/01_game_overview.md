## 1. 한 줄 소개

**클랜원 5명을 이끌어 적의 돌파를 막으며 100개 스테이지를 돌파하는 쿼터뷰 도트풍 턴제 전술·방어 RPG.** 플레이어는 직접 싸우지 않는 **지휘관**이 되어 용병단(클랜)을 키웁니다.

## 2. 세계관과 스토리

- 무대: 판타지 세계의 변경 마을 **솔빛 마을**에서 시작해 북방 설원, 남부 늪지, 화산의 볼카르 제국, 고대 문명의 심연, 하늘의 균열과 **마계**까지 이어집니다. 모험은 **10개 에피소드**.
- 발단 (에피소드 1 프롤로그): 15년 전 하늘이 갈라진 밤이 있었고, 그 잔해 속에서 **손바닥에 갈라진 별 모양 흉터**를 지닌 아이가 발견되었다. 시간이 흘러 마을 자경단장이 산적 화살에 쓰러지자 새 지휘관이 필요해진다.
- 후반부: 흉터는 "부모님이 남긴 열쇠"로 불리며, 마지막 에피소드의 목표는 **마계의 문을 모두의 손으로 잠그는 것**.

| EP | 제목 | 한 줄 줄거리 |
|---|---|---|
| 1 | 영웅의 시작 | 산적에게서 솔빛 마을을 지키고 도적 우두머리를 쓰러뜨려라 |
| 2 | 얼어붙은 음모 | 북방을 얼린 냉기의 정체와 흉터의 비밀을 쫓아라 |
| 3 | 늪지의 저주 | 습지에 퍼진 역병의 배후를 밝히고 습지의 제왕을 쓰러뜨려라 |
| 4 | 불타는 제국 | 내전 중인 볼카르 제국에서 화염 황제와 밀약의 진실을 밝혀라 |
| 5 | 심연의 종말 | 심연 깊은 곳으로 내려가 출생의 진실과 마주하라 |
| 6 | 지옥문 | 하늘의 균열이 번진 세상에서 지옥문을 막아라 |
| 7 | 악마의 영역 | 문 너머 마계로 들어가 오르딘을 쫓아라 |
| 8 | 신의 심판 | 신의 화신과 마계 사이에서 오르딘의 소환을 막아라 |
| 9 | 절체절명 | 연합군을 이끌고 마계 대군으로부터 세상을 지켜라 |
| 10 | 불가능의 영역 | 군주의 신하들을 넘어 모두의 손으로 마계의 문을 잠가라 |

- 주인공 지휘관의 기본 이름은 **리안**이며 플레이어가 바꿀 수 있습니다 (대사 안에서는 지정한 이름으로 나옵니다).
- 보스 16명은 각자 전용 초상화와 이름이 있습니다 (`04` 문서 3절). 고정 인물 5명 + 보스 16명 + 주인공 남/여 = 스토리 초상화 23장.
- 에피소드 7~8은 오르딘을 쫓고 그의 소환을 막는 이야기입니다 (에피소드 설명 기준; 개발 메모에는 오르딘이 "흑막" 역할이라고 적혀 있으나 대본 전체 줄거리는 이 문서에서 검증하지 않았습니다 [확인 필요]).
- 스토리 연출 방침(메모): 지휘봉은 **"전장에 나가지 않고 지휘만 하는 사람"의 상징**이며 명령·신호·작전 지시의 도구입니다. 음악·박자·연주 은유는 쓰지 않습니다. 지휘관 스킬은 삭제되었습니다 (커밋 c8477e5, 현재 `skills.json`의 지휘관 스킬 목록은 비어 있음).

## 3. 지휘관과 클랜원

| | 지휘관 | 클랜원 |
|---|---|---|
| 정체 | 주인공(리안). 남/여 선택, 이름 변경 | 용병단 아군. 12개 직업 |
| 전투 | **참가하지 않음.** 파티에서 자동 제외 | 파티 **5명**이 출전 |
| 성장 | 없음 (스토리 전용) | 레벨, 등급(C/B/A/S), 스킬, 장비, 전직·승급 |
| 죽음 | 해당 없음 | 쓰러지면 "사망" 표시 → 성소에서 부활 |

- 한국어 UI에서 아군을 **"클랜원"** 이라고 부릅니다 (사용자 지시 용어).
- 최소 5명 규칙: 살아 있는 클랜원이 5명보다 적으면 로비에 들어갈 때 **최근에 쓰러진 순서로 무료 자동 부활**합니다 (HP는 직업 기본값). 모두 쓰러져도 막다른 길이 없게 하는 안전장치입니다.
- 새 게임: **노비스 5명 + 지휘관 + 골드 2,000**, 파티 5개 슬롯.

## 4. 게임 흐름

```
로비 ─ 출격 ─▶ 스테이지 선택 ─▶ (전투 전 스토리) ─▶ 파티 편성 확인 ─▶ 전투 ─▶ (승리 후 스토리) ─▶ 결과·보상
   ▲                                                                                              │
   └──────────── 성장: 상점·성소·아카데미·편성(장비·강화) ◀─────────────────────────────┘
```

1. **로비**: 지휘관 설정(첫 실행), 전투 재개, 출격.
2. **스테이지 선택**: 에피소드→스테이지. 정보 창에서 적 구성·권장 레벨·전략 팁·보스를 보고 "일반 모드/연습 모드" 선택. **요일 던전**은 별도 입구.
3. **편성**: 5명 확인 (5명이 아니면 편성 화면으로). 장비·소모품·강화 탭에서 준비.
4. **전투** (`02` 문서): 틱 방식, 이동 후 행동 하나, 지형·위치 전술, 적 증원.
5. **결과**: 별 3개(클리어/무사망/턴 이내), 골드, 경험치(생존 클랜원이 나눠 받음), 첫 클리어 보너스·새 클랜원(스테이지 2·4·6·8 및 보스), 영혼석·룬·장비·스킬북 드롭, 전사자 목록.
6. **성장 루프**:
   - 레벨업(경험치) → 능력치 상승
   - 상점: 용병 모집, 장비 뽑기, 소모품, 스킬북, 전직서
   - 아카데미: 노비스 **전직**, 스킬북으로 **스킬 강화**
   - 성소: 쓰러진 클랜원 **부활**, 같은 직업 **제물로 승급**(C→B→A→S, 영혼석 필요), **개명**, 장비에 **룬 부여**
   - 편성의 장비 탭: 장착·판매·해체, 강화 탭: **강화**·수리
   - 요일 던전: 영혼석 조각·강화석·세트 장비 반복 수집
7. 다시 다음 스테이지로.

## 5. 승리·패배 조건 (요약)

- **승리**: 이번 스테이지의 적이 전부 등장한 뒤 모두 쓰러뜨림.
- **패배**: 클랜원 전멸 / **돌파한 적이 ⌈적 총수÷4⌉체 이상** / 항복.
- 쓰러진 클랜원은 사망 처리(연습 모드는 자동 부활). 상세와 별 조건은 `02`번 문서 10절.
- 전투 도중 **저장·이어하기**가 됩니다 (로비 "전투 재개").

## 6. 핵심 재미 요소 (기획 정리)

1. **위치 전술**: 등 뒤·옆구리·협공·고지로 최대 +40% 피해, 엄호(기사)와 투사체 차단, 숲 회피, 여울 약점.
2. **틱 순서**: 행동속도에 따라 누가 언제 움직일지 순서 바로 예측하고 이동·방향을 선택.
3. **성벽 방어**: 성문 앞 길목을 기사로 막고 원거리가 지원. 적은 성문을 부수거나 성벽을 넘거나 공성 아이템(폭탄 등)을 씁니다.
4. **육성의 깊이**: 12직업 × 등급 × 스킬 책 × 장비(강화·세트·전설) × 조합 버프.
5. **반복 콘텐츠**: 요일 던전, 별 3개, 연습 모드.
6. **다국어 6개 언어**와 가로 화면 모바일/PC 동시 출시 준비.
