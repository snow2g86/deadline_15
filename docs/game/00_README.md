## 이 문서 묶음의 규칙

- 모든 문서 맨 위에 **기준 날짜(2026-10-23)** 와 **근거 파일 목록**이 있습니다.
- 다른 문서에서 이미 설명한 내용은 번호로 가리킵니다 (예: "`02`번 문서 10절").
- 수치가 데이터와 코드에 모두 있으면 **코드가 실제로 쓰는 값**을 적고, 메모리(개발 기록)와 다르면 코드를 따랐습니다. 예: 별 보상은 개발 메모에는 "100+번호×10G"로 남아 있으나 현재 코드는 새 별 1개당 30+3×번호입니다.
- 이 문서는 읽기 전용 조사로 만들었습니다 — `godot/` 안의 코드·데이터는 수정하지 않았고, 시험은 새로 돌리지 않았습니다.
- 아직 진행 중인 작업(확률 표시 수정 등)이 작업 트리에 미커밋 상태로 있어, 그쪽 내용은 문서와 어긋날 수 있습니다.
