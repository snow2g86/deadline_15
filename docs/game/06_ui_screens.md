# 06. 화면 구성과 UI 방침

> 기준 날짜 2026-10-23 · 게임 버전 0.4.2 (`godot/project.godot` `config/version`)
> 근거 파일:
> - `godot/scripts/core/router.gd`
> - `godot/data/ui.json`
> - `godot/scripts/ui/*.gd (lobby, stage_select, party_select, shop, sanctuary, academy, compendium, guide, settings_screen, credits, licenses, screen_base)`
> - `godot/scripts/battle/README.md`
> - `godot/README.md (4a/4b/5단계/6a)`
> - `godot/scripts/core/{i18n,fonts,mobile,display,platform}.gd`
> - `godot/data/lang/ko.json`
> - `godot/project.godot`
>

> 화면 이름은 코드의 Router 이름(`boot`, `lobby` …)과 한국어 화면 제목을 함께 적었습니다.

## 1. 화면 목록 (13개)

`Router`(`scripts/core/router.gd`)가 화면 전환을 한 곳에서 관리합니다. 화면 이름 → 장면 파일은 아래와 같습니다.

| Router 이름 | 한국어 화면 | 역할 |
|---|---|---|
| `boot` | 시작 화면 | 잠깐 제목을 보여 주고 로비로 (약 0.6초). 개발용 `--dev` 옵션이면 전투 시험 실행기 |
| `lobby` | 로비 | 아지트(클랜원이 모여 있는 방), 골드 표시, **출격** 단추, 도감, 가이드, 전투 재개/포기, 지휘관 설정, 첫 실행 때 지휘관 이름·성별 정하기 |
| `stage_select` | 스테이지 선택 | 에피소드 카드(잠김/진행 중/완료·별), 스테이지 카드, 스테이지 정보(적 구성·권장 레벨·전략 팁), 일반/연습 모드, **요일 던전** 입구, **스토리 다시 보기** |
| `party_select` | 파티 편성 | 5개 파티 슬롯, 클랜원 카드, 탭 4개 = **파티 · 장비 · 소모품 · 강화** (`ps_active_tab`), **출격** 단추(파티 탭에서만, 스테이지를 고르고 온 경우에만 켜짐) |
| `shop` | 상점 | 탭 6개 (용병·소모품·장비·스킬·전직서·골드), 확률 정보 창, 인앱 결제, 광고 카드 |
| `sanctuary` | 성소 | 탭 4개 = **부활 · 승급 · 개명 · 마법부여**, 영혼석 보관함(조각 합치기) |
| `academy` | 아카데미 | 탭 2개 = **전직 · 스킬북** |
| `compendium` | 도감 | 탭 4개 = 직업 · 장비 · 소모품/재료 · 스테이지, 검색, 직업 상세 창 (데이터에서 바로 읽어 옴) |
| `guide` | 가이드(공략본) | 탭 7개 = 시작 · 성장 · 장비 · 전투 · 맵 환경 · 구간 공략 · 스토리(스포일러 접기, 보스 16명 초상화) |
| `settings` | 설정 | 언어 6개 · 배경음/효과음 · 게임 속도 · (PC) 화면 모드/창 크기/뒤에 있을 때 소리 · (모바일) 광고 개인정보 설정 · 모든 데이터 초기화 · 크레딧/라이선스 |
| `credits` | 크레딧 | 영어 그대로 |
| `licenses` | 오픈소스 라이선스 | Noto Sans 글꼴(OFL), Godot 엔진(MIT)과 엔진 구성 요소, V8 일부 이식 고지, 결제·광고 플러그인 고지 |
| `battle` | 전투 | 전투 장면 전체 (`02` 문서) — 로딩 → 스토리 → 전투 → 결과 |

## 2. 화면 이동 관계

```
시작 ──▶ 로비 ──▶ 스테이지 선택 ──▶ (출전 전 스토리) ──▶ [파티가 5명이면] 전투 ──▶ 결과 ──▶ 로비
          │            │                                   [5명 아니면] 파티 편성 ──▶ 출격
          │            └─ 요일 던전 창 ─▶ 전투 ─▶ 결과 ─▶ 스테이지 선택(요일 던전 창)
          ├──▶ 도감 / 가이드
          ├──▶ 설정 ──▶ 크레딧 / 라이선스
          └──▶ (아래 탭) 스테이지 · 파티 · 성소 · 아카데미 · 상점 ← 바깥 화면 어디서나 이동
```

- **아래 탭 5개** (`ui.json NAV_TABS`): 스테이지, 파티, 성소, 아카데미, 상점. 바깥 화면에서 항상 보입니다 (전투 중에는 없음).
- 윗줄: **뒤로 단추**(Esc 또는 마우스 뒤로 단추, 안드로이드 뒤로 단추도 같음 — 열린 창이 있으면 먼저 닫음), 화면 제목, **설정 톱니**.
- 로비에서 뒤로: PC는 아무 동작 없음, 안드로이드는 "게임을 종료할까요?" 확인.
- 화면 기록은 최대 16개까지 쌓이고, 로비로 가면 비웁니다. 전투 화면과 시작 화면은 기록에 남지 않습니다.
- **전투 결과 화면의 단추**: 로비로 / 다시 도전(일반 스테이지만) / 다음 스테이지. 요일 던전은 "스테이지 선택 + 요일 던전 창"으로 돌아갑니다.
- 상점 > 전직서를 아카데미에서, 편성의 장비 탭에서 상점으로 가는 바로가기가 있습니다.

## 3. 화면별 상세 (현재 코드 기준)

### 로비
- 가운데 **아지트**: 클랜원 그림이 모여 움직이는 장면 [확인 필요: 어떤 클랜원이 표시되는지] (모바일은 본문 높이에 맞춤). 골드 배지는 천 단위 쉼표(예: 5,000 G).
- 아래 단추 줄: [전투 재개(저장 전투가 있을 때)] · 도감 · **출격**(가장 눈에 띄는 단추) · 가이드. 전투 재개 오른쪽 위 ✕ = 포기(확인 창).
- 들어올 때마다 **저장값 점검**(이상한 값은 걸러내고 오류 없이 진행)과 **자동 부활**(살아 있는 클랜원이 5명 미만이면 최근 쓰러진 순서로 5명까지 무료 부활, HP는 직업 기본값)이 실행됩니다.
- 첫 실행: 지휘관 설정 창(닫을 수 없음) → 노비스 5명·지휘관·파티 5개·골드 2,000으로 새 게임.

### 스테이지 선택 / 파티 편성
- `04`번 문서 (해금·보상·요일 던전)와 `03`번 문서 (편성) 참고. 파티는 **정확히 5명**일 때만 출격 가능. 파티가 5개 저장됨.
- 편성 화면 **장비 탭**: 클랜원 카드의 장비 칸을 눌러 장착/해제/판매/해체/수리, 직업군 필터. **소모품 탭**: 경험치 물약 사용, 공성 아이템 보기. **강화 탭**: 강화·수리·확률 정보.

### 상점 / 성소 / 아카데미
- `05`번 문서 (상점), `03`번 문서 (전직·승급·부활).
- 성소 > 마법부여: 룬 + 100G로 장비에 부여.

### 도감과 가이드
- **도감**은 데이터에서 직접 읽어 수치가 항상 현재 값과 같습니다 (화면 맨 아래 "수치는 게임 데이터에서 바로 읽어 옵니다").
- 도감 부제 일부가 웹판 시절 문구(예: 스테이지 도감 "10개 스테이지의 난이도 분석")로 남아 있을 수 있습니다 [확인 필요: 실제 화면에서 100스테이지로 표시되는지].

### 설정
- 언어: 한국어 (Korean), English, Español, 日本語 (Japanese), 简体中文 (Simplified Chinese), 繁體中文 (Traditional Chinese) (단추 6개, 누르면 바로 바뀜).
- 배경음악 · 효과음 켜기/볼륨, 게임 속도(1x·2x·4x), 움직임 줄이기.
- PC만: 화면 모드(창 모드/전체 화면), 창 크기, 창이 뒤에 있을 때 소리(그대로/줄이기/끄기).
- 모바일만: 광고 개인정보 설정.
- 모든 데이터 초기화 (확인 창). 이 설정은 개발 빌드가 아닌 출시 빌드에서 `~/Library/Application Support/DEADLINE 15/`(맥) · `%APPDATA%\DEADLINE 15\`(윈도우)에 저장됩니다.

## 4. 다국어 (6개 언어)

| 언어 | 코드 | 글꼴 우선순위 |
|---|---|---|
| 한국어 | `ko` | KR → JP → SC → TC |
| English | `en` | KR → JP → SC → TC |
| Español | `es` | KR → JP → SC → TC |
| 日本語 | `ja` | JP → KR → SC |
| 简体中文 | `zh-CN` | SC → TC → KR |
| 繁體中文 | `zh-TW` | TC → SC → KR |

- 번역 원본: `godot/data/lang/<언어>.json` (같은 키 구조). 화면 글에는 `t("키")`로 접근하고, Godot 화면 전용 문구는 `gd.*` 아래에 있습니다. 스토리 대본은 `data/story/<언어>.json`.
- **기본 언어**: 저장된 설정 → 없으면 기기 언어 감지 → 6개 밖의 언어(프랑스어·독일어 등)는 **영어**.
- 번체(대만)와 간체(본토)는 따로 다듬었습니다 (기계 변환 금지, 개발 메모). 일본어·중국어 용어집: `docs/i18n/glossary.*.md`.
- 한국어에는 **조사 자동 선택**(이/가, 은/는 …)이 있습니다 (`josa.gd`, 한국어에만 적용, 영문 고유명사 등에서 틀릴 수 있음).
- 시험(`check_glyphs`, 언어별 넘침 시험)이 6개 언어 모든 글자가 글꼴에 있는지, 글이 단추 밖으로 넘치지 않는지 확인합니다.
- 중국 본토 심의 대비 용어 조정이 되어 있습니다 (예: 정치적으로 읽힐 말은 순화; 개발 메모).

## 5. 모바일 / PC 레이아웃 방침

| 항목 | PC | 모바일 |
|---|---|---|
| 기준 화면 | 논리 해상도 **1280×720**, 창 크기 자유(`canvas_items` + `expand`) | 같음 (**가로 고정**) |
| 창 크기 | 목록 8종(1024×576 ~ 3840×2160) 중 선택·드래그, **최소 1024×576**, 처음 실행은 모니터의 80% 안 가장 큰 크기 | 해당 없음 |
| 전체 화면 | Alt+Enter (맥 Cmd+Ctrl+F) | 항상 전체 |
| 입력 | 마우스·키보드 | 터치 (끌기=카메라, 두 손가락=확대, 길게 누르기=정보) |
| 크기 보정 | 없음 | 논리 1단위가 실제 0.136mm가 되도록 배율(1~1.6), **글자 최소 12pt, 누르는 것 최소 44pt** |
| 안전 영역 | - | 노치·홈 바를 피해 화면 요소 배치 (바탕·맵은 끝까지) |
| 전투 왼쪽 패널 | 폭 158px 카드 | 휴대폰 가로(논리 높이 600 미만 또는 폭 900 미만)는 폭 56px 아이콘형, 태블릿은 PC와 같음 |
| 행동 메뉴 | 한 줄 | 2열 |
| 소리 | 창이 뒤로 가면 줄이기(기본)/그대로/끄기 | 초점을 잃으면 바로 끔 |
| 광고 | 없음 | 상점 광고 카드 (AdMob 보상형) |

- **세로 화면은 지원하지 않습니다.** 2026-10-18 결정: "화면 방향 가로, PC 배치를 유지하고 글자·단추를 키우며 터치를 지원".
- 모바일 폰(논리 높이 약 480)에서 전투 맵이 좁아지는 문제는 "카드 줄 접기 같은 장치는 사용자 결정 후"로 남아 있었고, 이후 왼쪽 세로 패널(아이콘형)로 일부 해결했습니다. 실제 기기 확인은 [확인 필요].
- 아이콘/이모지: 설계 방침은 "이모지를 금테 유화풍 일러스트 아이콘으로 교체"이며, UI 기호(→ ✕ ↩ ★ ✓)는 글자로 유지합니다. 그림이 없는 이모지는 화면에서 지웁니다.
- 앱 아이콘은 **임시**입니다 (`09`번 문서).
