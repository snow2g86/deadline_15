# 🎭 게임 서사 (Story Arc)

## 📖 전체 줄거리

**테마**: 작은 마을의 자경대에서 시작한 평범한 클랜이 점차 세계의 위협을 마주하며 성장하여, 궁극의 악(마계)에 맞서 세계를 구하는 영웅담

---

## 🌍 에피소드별 서사

### 📍 Episode 1: 영웅의 시작 (Stage 1-10)
**보스**: 도적 우두머리

**배경**:
- 평화로운 농촌 마을이 산적단에 괴롭힘을 당하고 있다
- 마을의 청년들이 자경대를 구성하여 자신들의 마을을 지키려 한다
- 5명의 노비스(신입 자경단원)가 산적단 격퇴에 나선다

**스토리 진행**:
```
Stage 1-5: 마을 근처의 작은 전투들
         → 산적의 작은 거점들을 하나씩 격퇴
         → 클랜의 단합과 신뢰 쌓기
         → 첫 경험을 통해 서로 다른 역할 분담 시작

Stage 6-9: 산적단의 더 큰 거점 진격
         → 더 강한 적들과의 만남
         → 고급 무술가들(전사, 궁수 등)이 가세
         → 클랜의 전력 강화

Stage 10: 산적 우두머리 격퇴
        → 최종 보스 "도적 우두머리"와의 대결
        → 마을의 평화 회복
        → "이것이 끝이 아니다는 것을 느끼게 됨"
```

**주제**: 단합, 성장, 작은 승리가 모여 큰 변화를 만든다

---

### ❄️ Episode 2: 얼어붙은 음모 (Stage 11-20)
**보스**: 냉기 기사

**배경**:
- 마을을 구한 클랜의 명성이 퍼지기 시작한다
- 북쪽 산맥 지역에서 이상한 냉기가 뻗어 내려온다
- 여러 마을들이 얼어붙고 황폐해지는 현상 발생
- 클랜은 북쪽으로 파견되어 냉기의 원인을 조사하기로 한다

**스토리 진행**:
```
Stage 11-15: 북쪽 지역 탐험
           → 얼어붙은 마을들 구출
           → 냉기의 출처에 대한 단서 수집
           → 신비한 힘의 정체에 대한 의문 증가

Stage 16-19: 세력 확대 및 강화
           → 다양한 마법사들과 사제들이 클랜에 합류
           → 냉기 마법에 대한 대비책 강구
           → 북쪽 산맥의 깊숙한 곳으로 진군

Stage 20: 냉기 기사 격퇴
        → 보스 "냉기 기사" - 초자연적 힘을 사용하는 상대
        → 승리 후 발견: "이것도 누군가의 조종일 수 있다"
        → 더 큰 악의 그림자가 드러나기 시작
```

**주제**: 의문, 확대되는 위협, 개인의 선택이 세계에 영향을 미친다는 깨달음

---

### 🌿 Episode 3: 늪지의 저주 (Stage 21-30)
**보스**: 습지의 제왕

**배경**:
- 동쪽의 거대한 습지에서 괴이한 생명체들이 탄생하기 시작한다
- 습지 지역의 모든 생명이 오염되고 변이된다
- 로컬 주민들이 습지의 중심부로 향하는 클랜에 도움을 청한다
- 습지 깊숙이 숨겨진 고대의 것들이 깨어나고 있다는 전설

**스토리 진행**:
```
Stage 21-25: 습지 진입 및 오염 확대 확인
           → 변이된 생물들과의 전투
           → 습지 주민들의 절망감 목격
           → "이건 자연 재해가 아니다" 라는 깨달음

Stage 26-29: 습지의 중심부 탐험
           → 고대 유적 발견
           → 의도적인 오염의 증거 발견
           → 뒤에서 조종하는 더 큰 세력 암시

Stage 30: 습지의 제왕 격퇴
        → 보스 "습지의 제왕" - 고대 소환술사가 소환한 생명체
        → 승리 후: "여러 지역의 재해들이 모두 연결되어 있다"
        → 조직화된 악의 존재 확인
```

**주제**: 자연 파괴, 고의적 재난, 배후의 세력 인식

---

### 🔥 Episode 4: 불타는 제국 (Stage 31-40)
**보스**: 화염 황제

**배경**:
- 중앙의 거대한 제국이 급속도로 팽창하고 있다
- 제국의 마법사들이 각 지역의 재해를 계획적으로 일으키고 있음이 밝혀진다
- 제국은 혼란 속에서 땅을 집어삼키려 한다
- 클랜은 제국의 핵심 지역으로 진격하게 된다

**스토리 진행**:
```
Stage 31-35: 제국의 영토 진입
           → 제국군과의 첫 대면
           → 제국의 진정한 목표 파악
           → 지역 저항군들과 연합

Stage 36-39: 제국의 중추 도시 공략
           → 거대한 제국군과의 회전
           → 제국이 숨기는 더 어두운 비밀 발견
           → "제국도 누군가의 도구일 수 있다"는 의심

Stage 40: 화염 황제 격퇴
        → 보스 "화염 황제" - 제국의 최고 권력자
        → 승리 후 그의 입에서 진실 일부 나옴
        → "우리는 단지 예비일 뿐이다"
        → 더 강대한 악의 존재 확인 - 심연의 세력
```

**주제**: 권력, 조종, 개인의 욕심이 얼마나 파괴적인가

---

### 🌑 Episode 5: 심연의 종말 (Stage 41-50)
**보스**: 심연의 기사 / 심연의 전사

**배경**:
- 세계의 가장 깊은 지역 - 심연에서 초자연적 생명체들이 나타난다
- 심연은 세상이 아직 모르는 고대 문명의 폐허이다
- 거기서는 인간을 초월한 존재들이 거주하고 있다
- 클랜은 심연의 입구에 도달하고, 그곳의 진실을 마주한다

**스토리 진행**:
```
Stage 41-44: 심연 입구 탐사
           → 현재까지의 모든 적들이 심연에서 조종받았음 확인
           → 초자연적 생명체들과의 조우
           → 인간의 한계를 느끼기 시작

Stage 45: 심연의 기사 - 중간 보스
        → 심연의 하위 지배자 수준의 존재
        → 극도로 강력하지만 여전히 인간이 이길 수 있는 수준

Stage 46-49: 심연 더 깊숙이 진군
           → 고대 문명의 유산 발견
           → 심연의 진정한 목적 일부 이해
           → 클랜의 극심한 손실과 희생

Stage 50: 심연의 전사 - 최종 보스
        → 심연의 강력한 지배자 중 한 명
        → 승리 후: "우리는 더 큰 전투를 위한 준비 단계였다"
        → 마계(魔界)의 진입로가 열리고 있다는 경고
```

**주제**: 한계 극복, 희생, 인간이 초월할 수 있는가

---

### 🚪 Episode 6: 지옥문 (Stage 51-60)
**보스**: 옥문의 수호자

**배경**:
- 마계와 현실 세계를 잇는 차원의 문이 열리기 시작한다
- 차원의 균열을 통해 더 강력한 악의 세력들이 흘러나온다
- 전 세계가 혼란에 빠진다
- 클랜은 이제 세계의 마지막 희망이 된다

**스토리 진행**:
```
Stage 51-55: 차원의 균열 확대
           → 현실 세계와 마계의 경계 붕괴
           → 예전의 적들도 마계 세력에 복종한다는 것 확인
           → 세계적 위기 상황

Stage 56-59: 지옥문으로의 여정
           → 클랜의 진정한 목적이 드러남
           → 모든 것을 잃어가며 진군
           → 인간의 결연함이 빛나는 순간들

Stage 60: 옥문의 수호자 격퇴
        → 마계의 게이트를 지키는 강력한 존재
        → 승리 후: 마계의 본격적인 침략이 시작됨을 깨달음
        → "이제 최후의 전쟁이 시작된다"
```

**주제**: 절망 속의 희망, 마지막 저항

---

### 👿 Episode 7: 악마의 영역 (Stage 61-70)
**보스**: 악마의 법사

**배경**:
- 클랜이 마계에 직접 진입한다
- 마계는 인간의 이성과 상식이 통하지 않는 세상이다
- 강력한 악마들이 마계의 여러 지역을 지배하고 있다
- 마계의 세상이 서서히 현실 세계를 집어삼키고 있다

**스토리 진행**:
```
Stage 61-65: 마계 진입 및 적응
           → 마계의 법칙 이해하려 노력
           → 악마 지배자들의 강력함 체험
           → 인간적 감정과 싸우기 시작

Stage 66-69: 마계 심부로의 진군
           → 마계의 계층 구조 이해
           → 더 강력한 악마들과의 대면
           → 클랜의 정신적 한계에 도달

Stage 70: 악마의 법사 격퇴
        → 마계의 상층 지배자 중 하나
        → 승리 후: "최상위 지배자가 남아있다"
        → 마계 군주에 대한 정보 수집
```

**주제**: 이질성, 광기와 이성의 경계, 인간의 존엄

---

### ✨ Episode 8: 신의 심판 (Stage 71-80)
**보스**: 신의 소환사

**배경**:
- 마계의 깊숙한 곳에서 신비한 현상이 나타난다
- 신적 존재들이 마계와 현실 세계 사이에서 개입하기 시작한다
- 클랜의 행동이 신의 심판의 대상이 되는 상황
- 승리만이 유일한 길이다

**스토리 진행**:
```
Stage 71-75: 신적 현상과의 조우
           → 신의 화신들이 나타남
           → 클랜의 행동이 신의 뜻과 맞는지 의문
           → 신적 존재와의 대화를 통한 깨달음

Stage 76-79: 신적 심판에 맞서기
           → 신성한 존재들과의 전투
           → 자신들의 신념 재확인
           → 인간의 의지 vs 신의 뜻

Stage 80: 신의 소환사 격퇴
        → 신의 뜻을 대리하는 최고 존재
        → 승리 후: 신도 마계 군주를 막을 수 없다는 고백
        → 클랜이 유일한 희망임을 확인
```

**주제**: 신성성, 인간의 의지, 운명과 자유 의지

---

### ⚔️ Episode 9: 최후의 전쟁 (Stage 81-90)
**보스**: 전쟁의 전사

**배경**:
- 세계가 마계와 현실의 전쟁터가 된다
- 전 세계의 생존자들이 클랜과 함께 최후의 방어선을 구축한다
- 마계 군주의 대군이 세계를 집어삼키려 한다
- 이것이 승리와 멸망을 갈라놓는 최후의 전쟁이다

**스토리 진행**:
```
Stage 81-85: 전 세계적 동원
           → 마지막 저항군 결성
           → 모든 지역의 생존자들과 연합
           → 절망적이지만 의연한 각오

Stage 86-89: 연쇄 전투들
           → 마계의 여러 대군과의 격전
           → 동료들의 심각한 손실
           → 승리와 패배가 교대로 나타남
           → 끝까지 버티는 인간의 강인함

Stage 90: 전쟁의 전사 격퇴
        → 마계의 최상급 지배자 수준
        → 극적인 승리
        → "마계 군주로의 최종 진격이 가능해졌다"
        → 거의 모든 것을 잃었지만 희망이 남아있다
```

**주제**: 인류의 단합, 희생과 영광, 최후의 결전

---

### 👑 Episode 10: 운명의 종극 (Stage 91-100)
**보스들**: 최후의 기사 → 최후의 마술사 → 최후의 소환사 → 금지된 기사 → 마계의 전사 → **마계 군주**

**배경**:
- 마계의 가장 깊고 어두운 곳 - 마계 군주의 대좌로의 마지막 여정
- 마계 군주 주변의 최강의 위병들이 마지막 방어선을 구성한다
- 모든 것이 여기서 끝난다
- 승리하거나 세상이 영원히 어둠에 빠진다

**스토리 진행**:
```
Stage 91: 마계 심부 진입
        → 최후의 저항 지역 도달
        → 긴장감이 극도에 달함

Stage 92: 최후의 기사 격퇴
        → 마계 군주의 최고 신하
        → 최고의 기술과 명예를 가진 존재

Stage 93: 최후의 마술사 격퇴
        → 마계의 마법을 완벽하게 구사하는 존재
        → 거의 인간 이상의 지혜

Stage 94: 최후의 소환사 격퇴
        → 무수한 생명을 소환할 수 있는 존재
        → 파괴의 화신

Stage 95: 금지된 기사 격퇴
        → 인간이 되려던 악마
        → 가장 교활하고 위험한 존재

Stage 99: 마계의 전사 격퇴
        → 마계 군주의 최상급 근위대
        → 극도로 강력한 전사

Stage 100: 마계 군주 격퇴 (최종 보스)
         → 모든 악의 원천, 차원을 초월한 존재
         → 극적인 최종 전투
         → 승리: 세계의 재생, 새로운 시대의 시작
         → 패배: 영원한 어둠
```

**결말**:
```
승리 엔딩:
- 마계 군주 격퇴
- 마계와 현실 세계의 균열 봉인
- 희생한 모든 이들을 추도함
- 클랜이 영웅으로서 역사에 남음
- 세계는 천천히 회복 시작
- 마지막 대사: "우리는 평범했지만, 함께였기에 불가능을 이루었다"

패배 엔딩:
- 절망적인 상황에서 최선을 다함
- 마계 군주의 세계 침략 시작
- 하지만 그들의 저항 정신이 미래의 희망이 됨
```

**주제**: 운명, 모든 것을 걸고 싸운다는 것의 의미, 인간의 무한한 가능성

## 🎯 전체 서사의 흐름

| Episode | 테마 | 스케일 | 감정선 |
|---------|------|--------|--------|
| 1️⃣ 영웅의 시작 | 단합, 성장 | 마을 | 희망 ↗️ |
| 2️⃣ 얼어붙은 음모 | 의문, 확장 | 지역 | 의혹 ↗️ |
| 3️⃣ 늪지의 저주 | 파괴, 조종 | 국가 | 분노 → 결연 |
| 4️⃣ 불타는 제국 | 권력, 진실 | 대륙 | 투지 ↗️ |
| 5️⃣ 심연의 종말 | 한계, 희생 | 초차원 | 절망 ↗️ |
| 6️⃣ 지옥문 | 희망, 저항 | 다중차원 | 절망 → 희망 |
| 7️⃣ 악마의 영역 | 광기, 신념 | 마계 | 두려움 → 분노 |
| 8️⃣ 신의 심판 | 신성성, 의지 | 초월적 | 의문 → 확신 |
| 9️⃣ 최후의 전쟁 | 단합, 영광 | 세계 | 투지 ↗️ |
