## 🔧 구현 내용

### 1. AI 상황 분석 시스템
```javascript
// 분석 항목
- 체력 상태 (30% 미만 = weakened)
- 주변 아군 밀도 (3+ = surrounded)
- 이동 옵션 (0 = blocked)
- 근접 아군 (1+ = distant)

// 심각도 계산
severity = (1-hpPercent)*0.4 + (nearbyAllies/5)*0.4 + (1-moveOptions/4)*0.2
```

### 2. 공성아이템 시스템
```javascript
// 기본 지급: 적군 유닛당 1개 아이템
// 아이템 타입 (가중치):
- 💣 폭탄 (40%): 인접 아군 ATK*0.3 데미지
- 🛡️ 방어막 (30%): 데미지 50% 감소 (3턴)
- ⚡ 회피 (20%): 30% 확률로 공격 회피 (1턴)
- 🛣️ 우회로 (10%): 이동 경로 개선

// Cooldown: 사용 후 3턴
```

### 3. AI 의사결정 흐름
```
1. 스킬 사용 시도
2. 공성아이템 사용 시도 ← NEW
3. 근거리 공격
4. 게이트 공격
5. 벽 오르기
6. 이동
7. 이동 후 재공격
```

## 💡 설계 결정 근거

### 왜 공성아이템을 1개만 지급?
- 너무 많으면 난이도 급상승
- 1개는 특정 상황에서만 사용 가능
- 아군의 공성아이템과 동등함

### 왜 심각도 임계값 0.15?
- 0.15 미만: 안전한 상태 (아이템 사용 안 함)
- 0.15-0.5: 중간 상태 (선택적 사용)
- 0.5+: 위험 상태 (적극 사용)

### 왜 cooldown 3턴?
- 게임당 약 10-15턴 진행
- 3턴 = 게임의 약 20-30%
- 일회성 효과로 균형잡힘
