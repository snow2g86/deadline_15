# 스킬 밸런스 분석 (2026-10-08 갱신)

> 기준: `data/jab.js`(능력치·자원), `js/skills.js`(스킬 데이터), `js/skills/*.js`(실제 효과 — 수치는 코드 기준),
> `js/skills/_common.js`(calcDmg), `js/battle/turn.js`·`ai.js`·`buff.js`(지속·CC 처리).
> 피해 공식: 대부분 스킬 `max(1, ATK×배율×(1+0.1×(스킬Lv-1)) − DEF)`. 일반 공격만 calcDmg(버프·전술 보너스·여울·크리티컬) 적용.

## 4. 강한 직업 / 약한 직업

**강함**
- **지휘관**: 포르티시모(아군 전체 공·방 +20%)와 다 카포(추가 행동)가 파티 전체 화력을 끌어올림. 대신 본인 ATK 12·이동 2·쓰러지면 패배라 위험 부담이 큼. 직접 딜 없이 유지.
- **마법사**: 화염폭발 광역 + 일반 공격 스플래시 50% + 마나 가득 시작. 행동 속도 0.5가 유일한 제동 장치이므로 수치는 유지.
- **전사**: 강습이 분노 2로 가장 싸면서 이동+광역 → 분노 3으로 맞춤.

**약함**
- **주술사**: 핵심 스킬 3개가 사실상 작동하지 않았음(아래 5절 버그). 수정 후 디버퍼로 정상화. 수치는 그대로.
- **노비스**: 유일한 스킬(돌던지기)이 적 DEF에 막혀 1~3 피해. 입문 직업이라 약한 게 의도지만 "쓸 이유가 없는" 수준은 곤란 → 배율 상향 + 기본기 3종 추가.
- **궁수(저격)**: 기력 100(전부) 소모 대비 효율이 다른 궁수 스킬보다 낮음 → 비용 인하.
- **소환사**: 소환 80 마나로 5턴짜리 약한 소환수(정령 HP 50%·ATK 50%). 약한 편이지만 소환 강화·영혼 폭발·영적 유대 조합이 있어 이번에는 유지(관찰 대상).

## 5. 발견한 버그 (밸런스에 큰 영향, 수정함)

| # | 내용 | 영향 | 수정 |
|---|---|---|---|
| 1 | **적 차례에 기절·빙결을 확인하지 않음** (`turn.js` 적 분기가 바로 `AI.eAI` 호출) | 차징·빙결·함정 기절·적 대상 CC가 적에게 무효 | 적도 `UnitManager.isCC`면 행동 없이 차례 종료 + "💫 행동 불가" 표시 |
| 2 | **버프 지속이 절반**: `endUnitTurn`이 `BuffSystem.tick` 후 같은 `buffs[]`를 한 번 더 깎음 | "2턴" 버프(포르티시모, 함정 기절 등)가 실제 1턴 | 중복 감소 루프 제거 |
| 3 | 영혼 쇄도 속박이 `_rootedTurns` 필드를 쓰는데 적 이동은 `BuffType.ROOT`만 확인 | 속박 무효 | `ai.js eMv`·행동 예고에서 `_rootedTurns`도 확인 |
| 4 | 쇠약의 저주 피해가 아군 이동(`doMv`)에만 있고 적 이동(`AI._moveUnit`)에는 없음 | 적에게 걸면 효과 없음 (마나 100 낭비) | 공용 `curseMoveTick(u)`(shaman.js)로 양쪽에서 처리, 하드코딩 문구 제거 |
| 5 | 독안개가 `poisonMists`에 저장만 되고 처리 코드가 없음 | 피해 0 | 라운드 종료마다 `tickPoisonMists()` — 3×3 안 상대에게 ATK×0.3 (방어 무시·비치명), 3라운드 |
| 6 | `skills.js`의 `skillIcon`이 스프라이트 없는 스킬에 빈 문자열 반환 (지휘관 스킬 등 아이콘 없음) | 표시 문제 | 스프라이트가 없으면 스킬 데이터의 이모지로 표시 |
| 7 | 버프 아이콘 목록이 BuffSystem 버프(은신·회피·기절)를 ❄️로 표시 | 표시 문제 | 버프의 `icon` 우선 사용, 디버프 판정에 `_isDebuff` 반영 |
| 8 | 주술사 저주·고양·독안개 설명이 코드와 다름 ("매턴 1.0%… 이동/행동 불가") | 오해 | ko/en/es 설명을 실제 효과로 수정 |

> 참고: 버그 1·2 수정으로 CC·버프가 설계 수치대로 작동하면서 기사(차징)·마법사(빙결)·공병(함정)·지휘관(포르티시모)의 실효 가치가 올라갔음. 추후 플레이에서 함정(기력 20, ATK×2 + 기절 2)이 과하면 비용 30으로 조정 검토.

## 6. 신규 스킬

| 직업 | 이름 (ID) | 종류 | 효과 | 비용 | 스킬북 |
|---|---|---|---|---|---|
| 지휘관 | 🎵 피아니시모 (`commander_pianissimo`) | 습득형 | 반경 3칸 클랜원에게 2턴간 회피 버프 — 일반 공격 30% 확률 회피 (`BuffType.EVASION`, `rollEvade`) | 기력 40 | 1000G |
| 암살자 | 🌫️ 연막 (`assassin_smoke`) | 습득형 | 숲이 아니어도 다음 자기 차례가 끝날 때까지 은신 (`BuffType.STEALTH`, `isStealthed`) → 적 표적 제외, 습격 사용 가능. 직접 피해 없음 | 기력 40 | 800G |
| 노비스 | 🩹 응급처치 (`novice_firstaid`) | 습득형 | 자신 또는 인접 클랜원 최대 HP 15% 회복 | 기력 30 | 300G |
| 노비스 | 🏃 몸통 박치기 (`novice_tackle`) | 습득형 | 2칸 내 적 옆으로 달려들어 ATK×0.9 | 기력 25 | 300G |
| 노비스 | ✊ 근성 (`novice_grit`) | 패시브 | HP 30% 이하일 때 방어력 +30% | — | 300G |

설계 근거
- **피아니시모**: 기존 3개(공·방% / 회복·정화 / 추가 행동)와 겹치지 않는 "맞지 않게 하기" 축. 기대 피해 감소 ≈ 일반 공격 30%, 스킬·광역은 못 피함 → 포르티시모(DEF +20%)보다 변동성이 크고 평균은 비슷. 직접 딜 없음, 음악 용어(아주 여리게) 규칙 유지.
- **연막**: 은신을 숲 밖으로 가져오는 셋업기. 연막 40 + 습격 40 = 2차례·기력 80이 필요해 숲에서의 습격(40)보다 비싸고, 암살(적과 겹침)은 여전히 조건이 까다로워 폭발력은 그대로.
- **노비스 3종**: 모두 상위 직업 동종 스킬보다 약함 — 응급처치(15%, 단일) < 하모니(15% 광역+정화) / 사제 힐(ATK×1.5); 몸통 박치기(2칸·×0.9) < 습격(×2)·강습·돌격(×1.2); 근성(조건부 DEF+30%) < 철의 의지(DEF×1.5). 전직하면 사라지는 스킬이라 스킬북을 300G로 저렴하게(`bookCost`).

## 7. 수치 조정 (변경 전 → 후, 이유)

| 대상 | 변경 전 → 후 | 이유 |
|---|---|---|
| 노비스 돌던지기 배율 | ATK×0.5 → ATK×0.8 | 노비스 ATK 22 기준 11−DEF로 1~3 피해, 기력 15를 쓸 이유가 없었음. ×0.8도 일반 공격(ATK−DEF)보다는 약함 |
| 궁수 저격 비용 | 기력 100 → 60 | 기력 전부를 쓰는데 ATK×1.5 단일로 연속사격(50)과 비슷한 피해. 사거리 5~10 조건이 있어 60이 적정 |
| 전사 강습 비용 | 분노 2 → 3 | 5칸 돌진 + 광역 ×0.8이 단일 강타(3)·휘두르기(3)보다 쌌음 |
| 스킬북 가격 | 전부 800G(지휘관 1500G) → 스킬 데이터 `bookCost`가 있으면 우선 (노비스 300G, 피아니시모 1000G) | 전직 전용·약한 스킬이 같은 값이면 살 이유가 없음 |

## 8. 남은 관찰 항목
- 소환사 소환수 수치(정령 HP 50%·ATK 50%)가 낮음 — 버그 수정 후 플레이 데이터를 보고 조정.
- 독안개는 맵 위에 범위 표시가 없음(틱 시 이펙트·피해 숫자만) — 렌더러에 안개 칸 표시 추가 검토.
- `shaman_exalt` 관련 `calcDmg`의 `channeling === 'shaman_exalt'` 분기는 현재 설정하는 곳이 없는 죽은 코드.
