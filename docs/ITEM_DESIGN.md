# 장비 개편 기획서

> 구현: data/equip.js (틀·뽑기·강화·수리·분해) · data/gear.js (옵션·고유 효과·전설·세트·전투 효과) · 번역 data/language/*/gear.js

> 범위: 직업 전용 무기 · 공용 방어구 4종(천·가죽·사슬·판금)과 직업 전용 옵션 · 장비 고유 효과와 전설 장비 · 강화 +1~+10 재설계 · 직업 세트 장비
> 원칙: 골드는 항상 부족하게 · 강화는 위험하지만 성공하면 확실히 강하게 · 장비가 직업과 조합 전술을 더 뚜렷하게 만든다

## 1. 장비 구조

슬롯 8칸 유지: 무기 · 보조 · 투구 · 갑옷 · 장화 · 목걸이 · 귀걸이 · 반지

| 슬롯 | 착용 규칙 | 비고 |
|---|---|---|
| 무기 | **직업 전용** (12직업 각자 1계열) | 직업 정체성의 핵심 |
| 보조 | 계열 공용 (방패 / 마도서 / 소형 방패) | 기존 유지 |
| 투구·갑옷·장화 | **방어구 종류별 공용** (천·가죽·사슬·판금) + 직업 전용 옵션 | 사슬 신규 |
| 장신구 3칸 | 전 직업 공용 | 기존 힘·수호·신속 세트 유지 |

### 1-1. 직업 전용 무기

| 직업 | 무기 | 기본 능력치 성향 |
|---|---|---|
| 전사 | 대검 | 공격 높음 |
| 기사 | 기사검 | 공격 보통 · 체력 |
| 암살자 | 쌍단검 | 공격 높음 · 행동 속도 |
| 마법사 | 마법 지팡이 | 공격 · 자원 회복 |
| 궁수 | 장궁 | 공격 · 사거리 옵션 잘 붙음 |
| 사제 | 성표 | 공격 낮음 · 회복량 |
| 견습생 | 훈련용 검 | 고른 능력치 |
| 소환사 | 계약의 오브 | 공격 · 소환수 강화 |
| 주술사 | 토템 | 공격 · 디버프 강화 |
| 격투가 | 건틀릿 | 공격 · 연타 |
| 창기사 | 장창 | 공격 · 체력 |
| 공병 | 공병 망치 | 공격 · 공성 강화 |

### 1-2. 공용 방어구 4종

| 종류 | 성향 | 착용 가능 직업 |
|---|---|---|
| 판금 | 방어·체력 최고, 이동 옵션 안 붙음 | 기사 · 전사 · 창기사 |
| 사슬 | 방어·체력 중간, 고른 옵션 | 기사 · 전사 · 창기사 · 공병 · 사제 · 궁수 · 견습생 |
| 가죽 | 방어 낮음, 이동·행동 속도 옵션 | 전사 · 암살자 · 궁수 · 격투가 · 공병 · 견습생 |
| 천 | 방어 최저, 공격·자원 옵션 | 마법사 · 소환사 · 주술사 · 사제 |

### 1-3. 직업 전용 옵션

- 방어구에 **"[직업] 효과"** 옵션이 붙을 수 있다. 그 직업이 입었을 때만 켜지고, 다른 직업이 입으면 회색으로 표시돼 꺼진다.
- 직업은 그 방어구를 입을 수 있는 직업 중에서 무작위로 정해진다. (예: 판금 갑옷 → 기사·전사·창기사 중 하나)
- 무기는 원래 직업 전용이므로 전용 옵션이 항상 자기 직업 것으로 붙는다.

전용 옵션 예시 (직업당 3~4개 풀, 일부)

| 직업 | 옵션 |
|---|---|
| 기사 | 대신 맞기 피해 −15% · 넉백 저항 +15% · 인접 아군 방어 +8% |
| 전사 | 분노 획득 +1 · 체력 50% 이하일 때 공격 +15% |
| 궁수 | 사거리 +1 (낮은 확률) · 도움닫기 후 첫 공격 피해 +20% |
| 암살자 | 뒤에서 공격하면 피해 +20% · 처치 시 행동 게이지 +1 |
| 마법사 | 마나 회복 +3 · 광역 스킬 피해 +10% |
| 사제 | 회복량 +15% · 회복할 때 대상 디버프 1개 해제 (낮은 확률) |
| 창기사 | 돌진 피해 +15% |
| 공병 | 공성 도구 사거리 +1 |

## 2. 등급별 옵션 구성

| 등급 | 기본 능력치 | 추가 능력치 | 직업 전용 옵션 | 고유 효과 |
|---|---|---|---|---|
| D 일반 | O | − | − | − |
| C 고급 | O | 1개 | − | − |
| B 희귀 | O | 2개 | 1개 | − |
| A 영웅 | O | 2개 | 1개 | **무작위 고유 효과 1개** |
| S 전설 | O (높음) | 2개 | 1개 | **이름 있는 전설 효과 (고정)** |

추가 능력치 풀: 체력% · 공격% · 방어% · 행동 속도 · 자원 회복 · 치명타 확률 · 넉백 저항 · 환경 피해 감소

| 효과 | 내용 |

| 질풍 | 처치하면 행동 게이지 +1 |
| 결사 | 체력 30% 이하에서 공격 +30% |

|---|---|---|
| 피의 맹세 | 전사 대검 | 공격할 때마다 공격 +5% 누적(최대 5회), 처치하면 체력 10% 회복 |
| 불굴의 성벽 | 기사검 | 대신 맞기 피해 50% → 30%, 대신 맞을 때마다 분노 +1 |
| 그림자 송곳니 | 암살자 쌍단검 | 뒤에서 공격하면 피해 +50%, 처치하면 행동 게이지 +2 |
| 별무리 지팡이 | 마법사 지팡이 | 스킬 사용 시 30% 확률로 마나 소모 없음 |
| 바람의 속삭임 | 궁수 장궁 | 사거리 +1, 전투 첫 공격 치명타 (피해 +50%) |
| 새벽의 성표 | 사제 성표 | 회복량 +30%, 회복할 때 대상 디버프 모두 해제 |

| 망자의 토템 | 주술사 토템 | 거는 디버프 지속 +1턴, 효과 +20% |
| 철권 | 격투가 건틀릿 | 같은 대상을 연속 공격하면 피해 +20% 누적 |
| 관통의 창 | 창기사 장창 | 공격이 직선 뒤 1칸까지 관통 (뒤 대상 50%) |
| 파괴 공학 | 공병 망치 | 공격하면 대상 주변 적에게 30% 폭발 피해 |
| 용비늘 갑주 | 판금 갑옷 | 화상·화염 환경 피해 면역, 방어 +20% |
| 수호자의 사슬 | 사슬 갑옷 | 옆 아군이 받는 피해 −15% |
| 바람걸음 장화 | 가죽 장화 | 이동 +1, 더위(이동 감소) 면역 |
| 현자의 로브 | 천 갑옷 | 자원 회복 +50% |
| 왕의 인장 | 반지 | 파티 전체 공격 +5% (중복 불가) |
| 성자의 눈물 | 목걸이 | 쓰러질 때 1회 체력 30%로 버팀 |
| 시간의 귀걸이 | 귀걸이 | 전투 시작 시 행동 게이지 가득 |

획득처
- 보스 스테이지 클리어: 5% (첫 클리어 15%)
- 지옥 난이도 요일 던전: 3%
- 장비 뽑기 S 등급(천장 100회 유지)
- 이미 가진 전설이 다시 나오면 → 전설 조각 (조각 5개 = 원하는 전설 1개 교환)

## 3. 직업 세트 장비

- 직업마다 세트 3부위: 투구 · 갑옷 · 장화 (그 직업만 착용)
- 2세트 / 3세트 효과
- **파티 공명**: 같은 직업 세트 3부위를 갖춘 클랜원이 파티에 2명 이상이면 클래스 조합 버프가 1단계 강해짐 (예: 전사 5파티 광전사 버프 공격 ×2 → ×2.2)
- 획득처: **그 직업 요일 던전** 승리 시 보통 10% · 어려움 18% · 지옥 30% (지옥은 A 등급) — 요일 던전은 강화석도 2/3/5/8개
  → 요일 던전이 영혼석 조각 + 세트 장비 파밍처가 된다

세트 효과 (12직업)

| 세트 (직업) | 2세트 | 3세트 |
|---|---|---|
| 광전사 (전사) | 공격 +10% | 체력 30% 이하 피해 +25%, 처치 시 체력 8% 회복 |
| 성채 (기사) | 방어 +15% | 넉백 면역, 대신 맞는 피해 −20% |
| 야행 (암살자) | 행동 속도 +0.1 | 뒤에서 공격 +25%, 처치 시 행동 게이지 +1 |
| 대마도 (마법사) | 자원 회복 +4 | 치명타 +15%, 공격 +10% |
| 매의 눈 (궁수) | 치명타 +10% | 사거리 +1, 공격 +5% |
| 성가 (사제) | 회복량 +15% | 회복 시 50% 확률 디버프 해제, 체력 +10% |
| 신참 (견습생) | 체력 +10% | 받는 경험치 +30%, 공격 +8% |
| 계약자 (소환사) | 자원 회복 +3 | 소환수 능력치 +25% |
| 무녀 (주술사) | 자원 회복 +3 | 주술 디버프 +20%, 차례마다 30% 디버프 해제 |
| 투사 (격투가) | 행동 속도 +0.1 | 연속 공격 +10% 누적, 반격 +30% |
| 창성 (창기사) | 체력 +10% | 2칸 이상 이동 후 공격 +25%, 넉백 저항 +30% |
| 공병단 (공병) | 방어 +10% | 공격 시 주변 20% 폭발 |

---|---|---|
| 광전사 (전사) | 공격 +10% | 처치하면 분노 +3, 체력 30% 이하 받는 피해 −20% |
| 성채 (기사) | 방어 +15% | 넉백 완전 면역, 대신 맞기 범위 +1칸 |
| 야행 (암살자) | 행동 속도 +0.1 | 전투 시작 2턴 동안 은신(대상 지정 불가) |
| 대마도 (마법사) | 마나 회복 +4 | 광역 스킬 범위 +1 |

## 4. 강화 +1 ~ +10 재설계

### 4-1. 확률과 실패 처리

| 단계 | 성공 | 실패 시 |
|---|---|---|
| +0 → +1 | 100% | − |
| +1 → +2 | 90% | 유지 |
| +2 → +3 | 80% | 유지 |
| +3 → +4 | 70% | **−1단계** |
| +4 → +5 | 55% | −1단계 |
| +5 → +6 | 45% | −1단계 |
| +6 → +7 | 35% | −1단계 |
| +7 → +8 | 25% | −1단계 |
| +8 → +9 | 15% | −1단계 |
| +9 → +10 | 10% | −1단계 |

- 기본은 **실패 = 단계 하락** (+1~+3 입문 구간은 실패해도 유지)
- **파괴: 실패할 때마다 0.5% 확률** (모든 단계·모든 등급 동일)
- 파괴된 장비는 사라지지 않고 **파손** 상태가 된다: 자동으로 장착 해제, 장착·강화 불가
  - **수리**: 등급별 골드 — D 100 · C 200 · B 500 · A 1,200 · S 3,000
  - 수리하면 **강화가 +0으로 초기화**되고 강화 옵션이 모두 사라진다 (기본 능력치·추가 능력치·전용 옵션·고유/전설 효과는 유지)
  - 수리하지 않고 분해할 수도 있다 (강화석은 등급 기본량만)
- 연속 실패 보정: 실패할 때마다 다음 성공률 +3%p (최대 +15%p), 성공하면 초기화. 기존의 "3번 실패 → 100% 성공"은 폐지
- 보호 주문서: 사용하면 그 시도에서 파괴되지 않음 (단계 하락은 그대로)

### 4-2. 보상 (확실하게)

| 단계 | 기본·추가 능력치 | 마일스톤 |
|---|---|---|
| +1 | +10% | |
| +2 | +20% | |
| +3 | +30% | |
| +4 | +40% | |
| +5 | +55% | **고유·전설 효과 수치 ×1.25** |
| +6 | +70% | |
| +7 | +90% | |
| +8 | +110% | |
| +9 | +130% | |
| +10 | **+160%** | **고유·전설 효과 수치 ×1.5**, 이름 금빛, 직업 전용 옵션 수치 ×2 |

(기존: +10에서 +30%)

### 4-2-1. 강화 옵션 (성공 시 무작위 추가)

강화에 성공해 새 단계에 도달하면 확률적으로 **강화 옵션** 1개가 붙는다 (금색 표시).

| 도달 단계 | 강화 옵션이 붙을 확률 | 옵션 수치 | 나올 수 있는 옵션 |
|---|---|---|---|
| +1 ~ +3 | 25% | 낮음 | 체력% · 공격% · 방어% · 자원 회복 |
| +4 ~ +6 | 40% | 중간 | + 행동 속도 · 치명타 확률 · 넉백 저항 · 환경 피해 감소 |
| +7 ~ +9 | 60% | 높음 | + 이동 +1 · 사거리 +1 (희귀) · 처치 시 회복 등 약한 고유 효과 |
| +10 | **100%** | 최고 | +10 전용 풀: A 등급 고유 효과 중 1개 (이미 가진 효과와 중복 없음) |

- 옵션은 **그 단계에 묶인다**: 단계당 최대 1개, 평균적으로 +10까지 4~5개
- 단계가 **하락하면 그 단계의 강화 옵션은 사라지고**, 다시 오르면 새로 굴린다 → 하락이 아프지만 "더 좋은 옵션 재도전" 기회도 된다
- 파괴 후 수리하면 강화 옵션은 모두 소멸
- 같은 종류 옵션이 겹치면 수치 합산 (이동·사거리는 장비 1개당 최대 +1)

### 4-3. 비용 (골드 소모처)

- 골드: 등급 기본값 × (현재 단계 + 1)
  - D 40 · C 70 · B 120 · A 250 · S 500 → S 등급 +9→+10 한 번에 5,000G
- 강화석: +1~+3 1개 · +4~+6 2개 · +7~+9 4개
  - **분해**로 획득: 안 쓰는 장비 분해 → D 1 · C 2 · B 4 · A 8 · S 20개 (판매 골드보다 강화석이 더 가치 있게)
  - 보물상자 · 요일 던전 보상에도 소량
- 보호 주문서: 파괴 방지 (단계 하락은 그대로). 상점 1,500G, 보물상자 낮은 확률
- 강화석은 상점에서도 개당 200G에 판매 (골드 소모처)

## 5. 기존 저장 데이터 전환

- 기존 무기(한손검·단검·메이스 등) → 착용 가능 직업 중 첫 직업의 전용 무기로 바꾸고, 등급과 강화 단계는 유지
- 기존 방어구 → 같은 종류 그대로, 등급에 맞게 추가 능력치·전용 옵션·고유 효과를 새로 붙여 줌
- 기존 강화 +n → 새 능력치 배율 적용 (전부 상향)
- 연속 실패 카운트는 0으로 초기화
