# Plan: 특수상황 AI + 공성아이템 활용

## 개요
현재 AI 로직을 개선하여 **특수 상황에 대응**하고, **공성 아이템을 적극 활용**할 수 있도록 진화시킵니다.

## 목표
1. **특수 상황 감지**: 막혀있는 상황(진군 불가)에서 공성아이템 활용
2. **공성아이템 AI**: 적군이 기본적으로 1개씩 지급받아 전략적으로 사용
3. **동적 난이도**: 상황에 따라 AI의 공략 방식을 변경

## 주요 변경사항

### 1. 공성아이템 초기화 (적군용)
- **현재**: 사용자만 공성아이템 보유
- **변경**: 적군 유닛 생성 시 기본 1개 지급
- **파일**: `js/battle/boot.js` (유닛 생성 로직)
- **로직**:
  ```
  enemy 유닛 생성 → siegeItems 배열 초기화 (1개)
  ```

### 2. 공성아이템 검색 로직
- 적군이 보유한 공성아이템 목록 조회
- 사용 가능한 아이템 판단 (타입별 조건 확인)
- **파일**: `js/battle/ai.js` (새로운 함수 추가)

### 3. 특수상황 감지
- **상황 1**: 진군 불가능 (앞길이 장애물/벽으로 막힘)
  - 해결책: 폭탄/충격 공성아이템 사용
- **상황 2**: 아군과의 거리가 멀 때
  - 해결책: 사다리/우회로 공성아이템 사용
- **상황 3**: 체력이 낮을 때
  - 해결책: 방어막/회피 공성아이템 사용

### 4. 공성아이템 사용 함수 (AI용)
```javascript
async trySiegItemUse(u) {
  // 1. 보유 아이템 확인
  if (!u.siegeItems?.length) return false;

  // 2. 상황 분석
  const situation = analyzeSituation(u);

  // 3. 적절한 아이템 선택
  const item = selectSiegeItem(u, situation);

  // 4. 아이템 사용
  if (item) {
    useSiegeItem(u, item);
    return true;
  }
  return false;
}
```

### 5. AI 의사결정 흐름 개선
```
현재 흐름:
1. 스킬 사용
2. 적 공격
3. 게이트/벽 공격
4. 이동

개선된 흐름:
1. 스킬 사용
2. 공성아이템 사용 ← 새로 추가
3. 적 공격
4. 게이트/벽 공격
5. 이동
```

## 공성아이템 타입별 활용 시나리오

| 아이템 | 상황 | AI 조건 |
|--------|------|--------|
| 폭탄 | 길 막힘 | 앞 칸이 벽/장애물 2칸 이상 연속 |
| 사다리 | 높은 지형 | y > 8 (후방 영역) |
| 우회로 | 우회 필요 | 이동 경로가 2개 이상 막힘 |
| 방어막 | 체력 위험 | hp < maxHp * 0.3 |
| 회피 | 위험 회피 | 인접한 아군 수 > 2 |
