## 3. 현재 표시 점검

### 3-1. 잘 되어 있는 점
- 확률 창(`scripts/ui/odds_view.gd`)과 표(`scripts/logic/odds_rules.gd`)가 게임 데이터에서 계산되어 코드의 실제 확률과 일치. 반올림도 소수 3자리까지(`pct()`)라 4.5%, 0.45%, 0.05%가 정확히 표시됨.
- 장비 뽑기(등급별 + 11번째 확률), 천장, 룬 12종, 강화(단계별 성공·실패·하락/유지·파손·옵션), 실패 보너스 설명이 모두 있음. 검증 테스트도 있음(`tests/check_iap.gd:1408`).
- 6개 언어(ko/en/es/ja/zh-CN/zh-TW) 모두 `gd.odds` 29개 키 보유. 스토어 설명용 문서도 6개 언어(`docs/store/probabilities.*.md`).
- 스토어 등록정보에 "확률형 아이템 포함" 안내 문구가 있음(`docs/store/listing.ko.md:70` 등).

## 4. 결론

### 4-1. 법규 대상 여부 판정

- 판정: **대상(유력)**. 근거: 장비 뽑기·룬 뽑기·강화는 우연적 요소가 있고, 필요한 골드를 IAP로 살 수 있어 해설서의 "직접 또는 간접 유상" 기준을 충족. 스토어 심사·IARC 설문에서도 "랜덤 구매 있음"으로 답하게 되어 있음(`listing.ko.md:150`).
- 불명확: (1) 무료 드롭(상자·보스·요일던전)과 상점 용병 잠재력, 능력치 롤의 대상 여부, (2) 연평균 매출 1억 원 이하 중소기업 제외 적용 여부(신규 게임의 판단), (3) 해외/개인 사업자의 국내대리인·시정명령 적용. -> **전문가/공정위·게임물관리위 확인 필요.**
- 보수적 권장: 제외 가능성에 기대지 말고 전부 표시. Google Play·App Store 정책은 매출과 무관하게 적용됨.

### 4-2. 스토어 정책에 필요한 조치
- Google Play: 구매 전·구매 시점 가까이에서 확률 공개 -> 뽑기 카드 안에 요약 확률과 상세 보기 연결(아래 P0), 정책 선언·설문에서 랜덤 아이템 "예".
- App Store 3.1.1: 아이템 종류별 확률을 구매 전에 공개 -> 인라인 값 오류 수정과 종류별 확률 추가(P0, P1). 구매한 골드 비소멸 유지(현재 만료 없음).
- 공통: 설명문 마지막 줄 확률표 URL을 실제 주소로 교체(P1).
