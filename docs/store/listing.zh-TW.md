## 4. 詳細說明（4000 字以內）

```
在城門被攻破之前，擋下敵人。

DEADLINE 15 是一款回合制戰略守城RPG。你要組成由5名團員構成的隊伍，在等角視角的像素風地圖上一格一格地移動，阻止敵人突破並通過各個關卡。主角指揮官不親自上陣，而是在後方率領戰團。

■ 遊戲簡介
- 回合制戰術戰鬥：為每名團員選擇移動、攻擊或技能，一回合一回合地推進。
- 越過城牆的敵人（「突破」）達到一定數量即告失敗。用騎士堵住城門，讓遠程團員在後方支援。
- 共10個章節、100關，每10關會出現一名首領。
- 跟著指揮官與團員們的故事一路前進。

■ 戰鬥樂趣
- 活用地形：在森林中有機率閃避普通攻擊，丘陵上的遠程單位射程更遠、攻擊更強，站在淺灘裡的敵人會受到更多傷害。
- 背後攻擊、側擊、夾擊、掩護、擊退等站位戰術。
- 每種地圖都有不同的環境減益（酷熱、嚴寒、毒素、詛咒等），可用對應的附魔符文抵禦。
- 依據出戰隊伍的職業組成，為全員加上組合加成。
- 攻城道具、地圖上的寶箱、戰鬥中可使用的藥水。
- 敵人會越來越強。光靠等級是不夠的，需要綜合運用晉階、技能、裝備、組合與戰術。

■ 培育12種職業的團員
戰士、騎士、刺客、魔法師、弓箭手、祭司、初心者、召喚師、薩滿、武鬥家、槍術士、工兵。初心者可以在學院轉職為其他職業。
- 升級，並用技能書強化技能
- 在聖所以同職業團員作為祭品提升階級（C → B → A → S）。B→A、A→S 的晉階還需要魂石。
- 倒下的團員可以在聖所花費金幣復活。

■ 成長內容
- 每日地城：每天開放不同的職業，可取得該職業的魂石碎片。集滿碎片即可合成魂石。
- 裝備：各職業專用武器、通用防具、從首領與地城取得的傳說裝備與職業套裝。
- 裝備強化 +1 ~ +10：失敗時等級可能下降，裝備也可能損壞。使用保護卷軸可防止損壞。
- 附魔：用符文為裝備附加環境抗性與攻擊效果（烈焰之刃、霜凍、劇毒、雷霆、吸血、碎甲）。

■ 其他
- 支援6種語言：한국어、English、Español、日本語、简体中文、繁體中文
- 免註冊帳號即可開始
- 遊戲內圖鑑與攻略指南

■ 隨機道具機率說明
本遊戲含有隨機道具。
- 裝備抽取（商店）：各階級有不同的機率，並設有保底（連續100次抽取未出傳說時，第100次必出傳說）。
- 附魔符文抽取（聖所）：12種符文機率相同。
- 裝備強化：每個等級都有成功、失敗與損壞的機率。
完整機率表可在遊戲內商店與強化畫面的「機率資訊」以及下方網址查看。
機率表：[機率表網址 — 發布 docs/store/probabilities.zh-TW.md 後的網址 [확인 필요]]

■ 付費道具與廣告說明
- 金幣禮包（應用程式內購買，消耗型）：500 / 1,200 / 3,000 / 6,500 金幣。金幣可在遊戲中用於招募傭兵、復活、裝備抽取、強化等。金幣也可以透過遊玩取得。
- 獎勵廣告：完整觀看廣告可獲得 100 金幣（每天最多 3 次）。不看廣告也能正常遊玩。
- 廣告由 Google AdMob 提供。依所在地區，可能會跳出廣告隱私同意視窗，之後可在設定中更改選擇。
- 在 iOS 上，可能會請求您允許使用裝置識別碼進行追蹤。即使不允許，遊戲體驗也完全相同。
- 為了驗證購買，隨機產生的安裝 ID 與購買憑證資訊會傳送到購買驗證伺服器。詳情請見隱私權政策。
```
