- 한국에서 게임물은 게임물관리위원회(GRAC) 등급분류가 원칙이고, **오픈마켓 사업자(예: Google Play, App Store)는 자체등급분류 사업자로 지정**되어 스토어 설문으로 등급이 매겨지는 구조로 알고 있습니다. STOVE 가 PC 게임을 자체 분류할 수 있는지, 아니면 GRAC 에 직접 신청해야 하는지는 **확인 필요**입니다 [확인 필요: STOVE 개발자 센터, 게임물관리위원회].
- 한국 등급 표시: 전체 이용가 / 12세 이용가 / 15세 이용가 / 청소년이용불가. 예상 범위는 '12세 또는 15세 이용가' 정도로 짐작하지만 확정이 아닙니다 (판타지 전투, 확률형 아이템 포함).
