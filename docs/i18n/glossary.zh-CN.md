# DEADLINE 15 — 简体中文（zh-CN）术语表

> 기준: 한국어 원문 `data/language/ko/*.js`, `data/story/story.ko.js`
> 용도: zh-CN 번역의 통일 기준. 이후 대만 번체(zh-TW) 현지화의 바탕이 된다.
> **TW** 열: 대만에서 단순 번체 변환(简→繁)만으로는 부족하고 **다른 단어**를 쓰는 편이 자연스러운 항목. 비어 있으면 글자만 번체로 바꾸면 된다.
> 문장부호: 전각（，。！？：；「」『』……——）. 숫자·`{placeholder}`·HTML·이모지는 원문 그대로.

## 0. 핵심 원칙

| 항목 | 규칙 |
|---|---|
| 지휘관 성별 | 지휘관(`{commander}`)을 가리키는 他/她 금지. 이름·「你」·「指挥官」으로 쓴다 |
| 지휘봉 | **指挥杖**(군 지휘관의 杖). 「指挥棒」은 음악 지휘봉 느낌이 강하므로 금지. 음악 은유(乐章·节拍·演奏·和声·终曲) 금지 |

| 명령형 UI | 짧게: 「请选择…」 대신 「选择…」 허용 |

## 11-1. 본토 심의 대비 메모

- 이미 반영: 大陆→大地, 아군 반군 叛军→义军, 帝国临时政府→帝国残部, 동료 제물 祭品/献祭→素材/传承.
- 세계관이라 유지(심의 지적 시 대체안): 언데드 「亡灵·不死者」→「冰封傀儡·被操纵的士兵」, 피 묘사 「鲜血·血」→「红色·赤」, 해골 「人骨/骷髅」→「残骸」, 「吸血」 룬→「汲取」.
- 숫자·자리표시자와 한자 사이에는 띄어쓰기를 넣지 않는다(예: 「友军{count}人」「500金币」). 이하/이상은 「≤」「≥」.

## 12. 대만(zh-TW) 전환 시 주의 (요약)

- 단어 교체가 필요한 대표 항목: 设置→設定, 加载→載入, 数据→資料, 信息→資訊, 默认→預設, 开源许可→開放原始碼授權, 新手→初心者, 牧师→祭司, 法力→魔力, 晋升→晉階, 质量→品質, 屏幕→螢幕, 视频→影片, 应用内购买→應用程式內購.
- 文 스타일: 대만은 「」를 주 따옴표로 쓰는 경향이 강하다. zh-CN 대사는 “ ” 를 쓰고, 고유명사 강조는 「」.
- 인물·지명·스킬명은 글자만 번체로 바꾸면 된다(里安→里安, 塞拉→塞拉, 松光村→松光村).
