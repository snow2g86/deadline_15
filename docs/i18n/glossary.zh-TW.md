# DEADLINE 15 — 繁體中文（台灣，zh-TW）術語表

> 기준: 한국어 원문 `data/language/ko/*.js`, `data/story/story.ko.js` (zh-CN 번역은 참고용일 뿐, **원문은 항상 한국어**)
> 출발점: `docs/i18n/glossary.zh-CN.md` — 여기에 대만 게임업계 관용(용어·음역·양사·UI 동사·문장부호)을 적용했다.
> 원칙: 간체→번체 **글자 변환이 아니다.** 매 문장을 한국어에서 다시 읽고 대만 화자가 쓰는 표현으로 쓴다.
> 숫자·`{placeholder}`·HTML 태그·`\n`·이모지는 원문 그대로. 간체 전용 글자 금지(검사 스크립트로 확인).

## 0. 핵심 원칙

| 항목 | 규칙 |
|---|---|
| 지휘관 성별 | 지휘관(`{commander}`)을 가리키는 他/她 금지. 이름·「你」·「指揮官」으로 쓴다 |
| 지휘봉 | **指揮杖**. 「指揮棒」 금지. 음악 은유(樂章·節拍·演奏·和聲·終曲) 금지 |
| 지휘관은 전투 불참 | 전투 대사에서 지휘관은 후방에서 명령만. 衝鋒·負傷 묘사 금지 |
| 클랜원 / 클랜 | **團員** / **戰團** (「公會」는 길드 느낌이라 쓰지 않음) |
| 명령형 UI | 짧게. 「請選擇…」 대신 「選擇…」 허용. 버튼은 2~4자 |
| 글자 표준 | 대만 교육부 표준자형: 裡(裏 X), 著(着 X), 線, 為, 臺/台는 「台」 허용, 吃, 峰, 麵, 群, 衛, 床, 敘, 污→汙 X(污 허용) |
