# DEADLINE 15 — 日本語 (ja) 용어집

원문은 한국어(`data/language/ko`, `data/story/story.ko.js`). 영어·스페인어는 뜻 확인용 보조 자료.
아래 표의 일본어를 **모든 파일(UI·도감·스토리)에서 똑같이** 쓴다.

## 0. 문체 원칙

- UI 버튼·라벨: 짧게. 체언 끝맺음(「出撃」「装備」「強化」), 동사형 버튼은 한자어 명사(「購入」「売却」「分解」).
- 안내·설명문: です・ます체. 확인 대화: 「〜しますか？」.
- 한국어 문장부호: `?`→`？`, `!`→`！`, `…`/`……`는 그대로, `·`(가운뎃점)→`・`, 인용 `"…"`→`「…」`, 『』는 작품·이름 강조용.
- 숫자·단위·자리표시자(`{n}` `{cls}` `{gold}` `<b>` `\n` 이모지)는 원문 그대로 둔다. `G`(골드 단위)는 그대로.
- 조사 분기 `을(를)`, `이(가)`, `(으)로` 같은 한국어 조사 처리는 일본어에서 필요 없으므로 「を」「が」「に」로 단순화.

## 16. 검수 반영 규칙 (2026-10-14)

- 산적 = 「山賊」(山賊団). 「盗賊」은 보스 「盗賊の頭目」에만 쓴다.
- 균열 = 「裂け目」(「亀裂」 쓰지 않음). 잿빛 평원 = 「灰の平原」. 바크가 브람/오르딘을 부르는 영감 = 「爺さん」.
- 오르딘이 지휘관을 부를 때는 항상 「貴殿」.
- 지휘관 대사에 「〜ぞ」「〜ぜ」 등 성별이 느껴지는 어미를 쓰지 않는다 (〜よう／〜う、명사·평서 종결로).
- 세라의 대표 대사: 「怪我したら私が治してあげる。」 (怪我는 한자 표기로 통일).
- 연도: 「15年」 (아라비아 숫자). 승급 점수 단위: 「点」.
- 스킬명과 전투 팝업은 같은 말: 爆炎／奇襲／苦痛分担／捕獲／霊魂奔流. 스턴·기절 = 「気絶」. 도움닫기 = 「踏み台」(도약 「跳躍」과 구분).
- 문장부호: 전각 「：」「（）」「…」(UI의 시간 표기 `{hours}:{minutes}` 같은 숫자 사이 콜론은 반각 유지). 스토리에서 문중 「！」「？」 뒤에는 전각 공백 「　」, 닫는 괄호·문장 끝 앞에서는 공백 없음.
